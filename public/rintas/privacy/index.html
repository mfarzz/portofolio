Kebijakan Privasi Rintas

Dokumen ini menjelaskan data yang dipakai aplikasi Windows Rintas ketika pengguna berbagi file langsung dari laptop atau melalui Google Drive miliknya.

Berlaku sejak: 12 November 2026

Pengelola: Muhammad Fariz

Kontak privasi: mfarix730@gmail.com

Data yang diproses

Rintas membaca file yang dipilih pengguna untuk mengetahui nama dan ukuran file serta mengirimkan isinya kepada penerima. Rintas menyalin tautan berbagi ke clipboard. Pada mode langsung, Rintas membuat kunci tautan acak dan menyimpan lokasi file serta waktu kedaluwarsa tautan dalam memori selama sesi aplikasi berjalan.

Di komputer pengguna, Rintas menyimpan mode berbagi, alamat domain, masa berlaku bawaan tautan lokal, Google OAuth Client ID aplikasi, dan nama serta ID folder Drive tujuan dalam config.json. Rintas juga menyimpan token pengendali server lokal dalam control.token. Berkas ini berada di folder %LOCALAPPDATA%\FileShareTunnel.

Jika pengguna menghubungkan Google Drive, token Google disimpan di google-drive-token.dat dan dienkripsi dengan Windows DPAPI untuk akun Windows yang sedang dipakai. Rintas tidak menyertakan token pengguna dalam paket installer. Log lokal rintas.log dapat berisi waktu aktivitas, nama file yang dibagikan secara langsung, jumlah sesi, alamat tunnel, dan pesan galat.

Berbagi langsung dari laptop

Rintas memakai Cloudflare Tunnel agar tautan HTTPS dapat mencapai server yang berjalan di laptop pengirim. Permintaan penerima dan isi file melintasi jaringan Cloudflare. File asli tetap di laptop; Rintas tidak mengunggah salinannya ke server milik pengelola Rintas. Laptop dan tunnel harus menyala saat penerima mengunduh. Cloudflare dapat memproses lalu lintas menurut kebijakan privasinya.

Halaman unduhan lokal menampilkan nama file, ukuran, dan waktu kedaluwarsa. Server Rintas tidak membuat log khusus alamat IP penerima, memasang cookie pada halaman unduhan, atau menambahkan iklan dan analitik. Siapa pun yang memiliki tautan lengkap dapat mengunduh file sampai tautan berakhir atau dicabut.

Login dan unggah ke Google Drive

Mode Google Drive hanya dipakai setelah pengguna menekan Login Google, memilih akun sendiri di browser, dan menyetujui izin https://www.googleapis.com/auth/drive.file. Izin ini dipakai Rintas untuk membuat folder dan file milik aplikasi di Drive pengguna, mengunggah file yang dipilih, serta membuat izin baca pada file hasil unggahan.

Rintas mengunggah salinan file ke folder Rintas di My Drive pengguna. Setelah unggahan selesai, Rintas membuat izin siapa pun yang memiliki tautan dapat melihat atau mengunduh, lalu menyalin tautannya. Orang yang menerima tautan dapat melihat nama dan isi file melalui layanan Google Drive. Google memproses data tersebut sesuai Kebijakan Privasi Google. Pengelola Rintas tidak menerima salinan file atau token Google pengguna.

Rintas menggunakan data Google hanya untuk fungsi berbagi yang dipilih pengguna. Rintas tidak menjual data Google, menggunakannya untuk iklan, atau mengirimkannya ke layanan analitik milik pengelola aplikasi.

Penyimpanan, masa berlaku, dan penghapusan

Pada mode langsung, tautan aktif disimpan dalam memori dan berhenti saat masa berlaku habis, tautan dicabut, server berhenti, atau pengguna keluar dari Rintas. Masa berlaku bawaan adalah 24 jam dan dapat diubah dari 1 menit hingga 7 hari. Rintas tidak membuat salinan tetap file asli pada mode ini.

Pada mode Google Drive, salinan file tetap berada di Drive pengguna sampai pengguna menghapusnya. Masa berlaku dan tombol cabut tautan lokal Rintas tidak mengubah izin file Drive. Menutup Rintas atau menghapus file asli di laptop juga tidak menghapus salinan Drive. Pengguna dapat menghapus file atau mengubah izin berbagi langsung di Google Drive.

Tombol Putuskan akun menghapus token Google yang tersimpan di komputer, tetapi tidak menghapus file Drive atau mencabut izin aplikasi pada akun Google. Pengguna juga dapat mencabut akses Rintas melalui pengaturan keamanan akun Google. Berkas pengaturan dan log lokal tetap ada sampai dihapus pengguna; log belum dihapus otomatis. Rintas tidak dapat menghapus salinan yang sudah diunduh penerima.

Keamanan dan pilihan pengguna

Pengguna memilih file, mode berbagi, folder tujuan Drive, domain untuk mode langsung, dan kapan tautan lokal dicabut. Token Google dienkripsi untuk akun Windows pengguna. Tautan berbagi harus dikirim hanya kepada orang yang dituju karena siapa pun yang memperoleh tautan lengkap dapat mengakses file sesuai izin yang berlaku. File sensitif sebaiknya tidak diberi izin “siapa pun yang memiliki tautan”.

Jika Anda penerima tautan dan ingin meminta akses, koreksi, atau penghapusan file, hubungi pengirimnya. Untuk pertanyaan tentang cara aplikasi memproses data, hubungi mfarix730@gmail.com.

Layanan lain dan perubahan kebijakan

Jika Rintas diperoleh melalui Microsoft Store, data terkait Store, pemasangan, dan pembaruan diproses Microsoft menurut Pernyataan Privasi Microsoft. Pemrosesan ini terpisah dari fungsi berbagi Rintas.

Kebijakan ini dapat diperbarui ketika cara kerja Rintas berubah. Tanggal berlaku akan diperbarui, dan versi terbaru akan tersedia di alamat halaman ini.
