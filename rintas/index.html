APLIKASI BERBAGI FILE UNTUK WINDOWS

Bagikan file dari laptop. Pilih cara penerimanya mengakses.

Rintas membuat tautan berbagi dari menu klik kanan Windows. Gunakan koneksi langsung dari laptop untuk berbagi sementara, atau unggah salinan ke Google Drive milik Anda agar file tersedia ketika laptop mati.

DUA CARA BERBAGI

Anda memilih lokasi file yang dibagikan.

01 / LANGSUNG

Dari laptop

File tetap di laptop. Rintas membuat tautan melalui Cloudflare Tunnel. Laptop dan Rintas harus menyala saat penerima mengunduh; kecepatan unduh dipengaruhi kecepatan upload laptop.

02 / GOOGLE DRIVE

Dari Drive Anda

Rintas meminta Anda login ke Google, lalu mengunggah salinan ke folder Rintas di Drive Anda. Setelah unggah selesai, penerima dapat membuka tautan walaupun laptop Anda mati. Siapa pun yang memiliki tautan dapat mengakses file tersebut.

ALUR SINGKAT

Tiga langkah untuk berbagi.

01 / PILIH

Klik kanan file di Windows atau pilih file dari menu tray Rintas.

02 / BAGIKAN

Rintas membuat tautan lokal atau mengunggah file ke Google Drive sesuai mode yang dipilih.

03 / KIRIM

Tautan disalin ke clipboard setelah siap. Tempel ke percakapan dengan penerima.

Privasi dan kendali

Mode langsung menyimpan file hanya di laptop. Mode Google Drive menyimpan salinan di akun Drive pengguna; izin dan penghapusannya dikelola di Drive. Rintas tidak mengirim file atau token Google ke server milik pengelola Rintas. Penjelasan lengkap tersedia di Kebijakan Privasi Rintas.
